# Modern Car Care — React + Vite

Premium single-page car-care website with responsive navigation, reveal-on-scroll transitions, marquee, service cards, contact section, and a locally stored animated MP4 hero background.

## Run locally

```bash
npm install
npm run dev
```

Create a production build with `npm run build`.
